# 💱 Conversor de Moedas

Converta valores entre diferentes moedas com cotação real e atualizada!

**🔗 Acesse o projeto online:** https://jobsonbertosilva.github.io/conversor-de-moedas/

## ✨ O que o projeto faz

- Converte valores entre Real (BRL), Dólar (USD) e Euro (EUR)
- Busca a cotação atualizada em tempo real via API
- Mostra o resultado formatado com o símbolo da moeda
- Permite inverter a conversão com um clique
- Valida se o valor digitado é válido
- Layout responsivo, funciona no celular e no computador

## 🛠️ Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Fetch API para consumo de API externa

## 🌐 API utilizada

Este projeto utiliza a **ExchangeRate-API** para buscar as cotações atualizadas das moedas em tempo real.

- Site da API: https://www.exchangerate-api.com/
- As taxas não ficam fixas no código, elas são buscadas direto da API toda vez que você faz uma conversão.

## 🚀 Como usar

1. Digite o valor que você quer converter (ex: 100)
2. Escolha a moeda de origem (ex: Real)
3. Escolha a moeda de destino (ex: Dólar)
4. Clique em "Converter"
5. Veja o resultado com a cotação atualizada!
